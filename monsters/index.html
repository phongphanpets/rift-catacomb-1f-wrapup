AUTO ATTACK

Ghost Slap

ลอยเข้าประชิดแล้วกระแทกเป้าหมายหนึ่งคน ดาเมจเบา ไม่มีผลกับคนรอบข้าง

วิธีรับมือ: ถ้าออกนอกระยะก่อนจังหวะโดน ท่าจะพลาด จากนั้น Ghost เคลื่อนตาม

อ่านกติกาละเอียด · Ghost Slap
  • เตรียมกระแทกสั้น ๆ ใช้ Animation Attack ที่มี ไม่มีพื้นที่เตือนบนพื้น คิดดาเมจครั้งเดียวต่อเป้าหมาย
  • ไม่มี Frontal / AoE / Knockback / Stun / Debuff หรือการหลบกายภาพพิเศษ ไม่เรียกผีอื่นเข้าต่อสู้อัตโนมัติ
  • ไม่เริ่มสู้กับผู้เล่นที่เดินผ่าน ตอบโต้คนโจมตีก่อน หากมีระบบ Threat ใช้ผู้มี Threat สูงสุด
  • ระยะ ความถี่ HP และดาเมจจริงยังไม่ล็อก ข้อความแก้ล่าสุดไม่ได้ระบุระยะกับรอบโจมตี จึงไม่เติมค่าเก่า 1 Grid / 2s กลับมา
COMBAT FLOW

ถูกโจมตี → เข้าประชิด → Ghost Slap → พักตามรอบ → โจมตีซ้ำ

รอยืนยัน

ระยะโจมตี รอบโจมตี HP / Damage และระยะไล่ตามต้องกำหนดร่วมกับ Core และทดสอบตามโซน

การจบไฟต์

เป้าหมายตายหรือหลุดระยะไล่ตามและไม่มี Target อื่น ใช้ Default Monster Reset ด้านล่าง ไม่ไล่เข้า Safe Zone

AUTO ATTACK

Arrow Shot

ยิงใส่เป้าหมายหนึ่งคน ดาเมจเบาถึงปานกลาง ไม่มีท่าพิเศษหรือ Debuff

ระยะ ~5 Gridยิงทุก ~2.5s

วิธีรับมือ: ก่อนปล่อยการยิง หากเป้าหมายพ้นระยะหรือเข้าหลังกำแพง ให้ยกเลิกและเดินหาตำแหน่งยิงใหม่

อ่านกติกาละเอียด · Arrow Shot
  • หันหาเป้าหมายและใช้ Animation ง้างธนู ไม่มีวงเตือนบนพื้น ต้องมี Line of Sight ไม่ยิงทะลุกำแพง
  • เดินเข้าหาเมื่อยิงไม่ได้ แล้วหยุดเพื่อยิง ไม่ยิงระหว่างเคลื่อนที่ ผู้เล่นเข้าประชิดก็ยังยิง ไม่ถอยหรือเปลี่ยนเป็นท่าประชิด
  • ไม่เรียกมอนใกล้เคียงเข้าต่อสู้อัตโนมัติ ไม่ยิงเข้า Safe Zone
  • Core direction: เลี่ยง True Projectile ที่ตรวจตำแหน่งและการชนต่อเนื่อง วิธีแสดงภาพยิงกับจังหวะคิดผลต้องแยกกัน และยังต้องยืนยัน Range / LOS / การยกเลิกกับ Dev ไม่ถือว่าเป็น Hit-scan หรือโดนอัตโนมัติ
  • กติกายกเลิกก่อนปล่อยเป็นเจตนาดราฟเดิม ส่วนจังหวะคิดผลหลังปล่อย รวมเป้าหมายตายหรือเปลี่ยน LOS ยังต้องให้ Dev ยืนยัน ไม่เพิ่มระบบบังลูกธนูกลางทาง
COMBAT FLOW

ตรวจพบผู้เล่น → เข้าระยะและมี LOS → ง้าง → Arrow Shot → พักตามรอบ → ยิงซ้ำ

อ่านกติกาละเอียด · Sword Strike

02
ACTIVE · FRONTAL

Sweeping Slash

ง้างดาบแล้วฟันผู้เล่นทุกคนในกรวยด้านหน้า ดาเมจหนักกว่า Auto-Attack

ระยะ ~3 Grid · มุม 90°เตือน 1.5sพักหลังฟัน ~0.7s

วิธีรับมือ: ออกจากกรวยด้านข้าง ทิศถูกล็อกตั้งแต่เริ่มเตือนและไม่หมุนตาม

อ่านกติกาละเอียด · Sweeping Slash
  • มีกรวยบนพื้นและท่าง้างดาบแนวนอน หยุดเดินและหยุด Auto-Attack ระหว่างง้าง
  • เริ่มง้างเมื่อเป้าหมายอยู่ในระยะประชิด ถ้าผู้เล่นหนีหลังเริ่ม ยังฟันทิศเดิม ไม่ยกเลิกหรือไล่ตามกลางท่า
  • คิดดาเมจครั้งเดียว ไม่มีพื้นอันตรายตกค้าง ไม่มี Knockback / Stun / Debuff
  • หลังฟันพักประมาณ 0.7 วินาที แล้วกลับไปไล่โจมตีเป้าหมาย
  • ครั้งแรกหลังเริ่มสู้ประมาณ 3–4 วินาที ใช้ซ้ำประมาณทุก 8–10 วินาที จุดเริ่มนับรอบซ้ำยังไม่ระบุ
  • หน่วย Grid ไม่ได้กำหนดจุดอ้างอิงวัดระยะโดยอัตโนมัติ ต้องตกลงกับ Collision และขนาดโมเดล
COMBAT FLOW

เข้าต่อสู้ → Sword Strike → Frontal แรก ~3–4s → พัก → กลับไล่โจมตี → ใช้ Frontal ซ้ำ

รอยืนยัน

รูปแบบเริ่ม Aggro / การเรียกพวก รอบและระยะ Auto-Attack จุดเริ่มนับ CD ของ Frontal และการวัดระยะ

การจบไฟต์

ใช้ Default Monster Reset ไม่เติมความสามารถโล่บล็อกหรือลดดาเมจจากภาพอาวุธ

01
MAIN ATTACK · INTERRUPTIBLE

Chilling Bolt

ร่ายเวทน้ำแข็งใส่เป้าหมายหนึ่งคน สร้างดาเมจเวทเบาถึงปานกลางพร้อม Chilled ไม่มี Auto-Attack แทรก

ระยะ ~5 Gridร่าย ~1.5sพักปกติ ~3s

วิธีรับมือ: Interrupt ได้ หรือออกนอกระยะ / ตัด LOS ก่อนร่ายจบเพื่อให้ยกเลิกเวท

อ่านกติกาละเอียด · Chilling Bolt
  • Cast Bar และเอฟเฟกต์น้ำแข็งที่ปลายคทา หยุดเดินระหว่างร่าย ไม่มีวงเตือนบนพื้นเพราะเจาะจงเป้าหมาย
  • ดราฟเดิมตรวจ LOS ตอนเริ่มและตอนปล่อย หากพ้นระยะหรือหลังกำแพงก่อนร่ายเสร็จ ยกเลิกแล้วเดินหามุมใหม่ ไม่ร่ายผ่านกำแพง
  • เมื่อถูก Interrupt ยกเลิกเวท พักประมาณ 2 วินาทีก่อนเริ่มใหม่ ใช้แทนช่วงพักปกติ 3 วินาที ไม่บวกสองช่วงเข้าด้วยกัน
  • เมื่อถูกประชิดยังร่ายตามปกติ ไม่ถอยหนี ไม่เรียกมอนใกล้เคียงอัตโนมัติ
  • คิดดาเมจและ Debuff ครั้งเดียวต่อเป้าหมาย เจตนาเดิมเป็นเวท Targeted ส่วน Homing / Visual travel และเวลาคิดผลต้องตกลงกับ Core
  • Core direction: เลี่ยง True Projectile ที่ตรวจตำแหน่งและการชนต่อเนื่อง วิธีแสดงภาพยิงกับจังหวะคิดผลต้องแยกกัน และยังต้องยืนยัน Range / LOS / การยกเลิกกับ Dev ไม่ถือว่าเป็น Hit-scan หรือโดนอัตโนมัติ
  • กรณีเป้าหมายตายก่อนผลเวทเกิด การยกเลิก และ LOS / Range ก่อนคิดผลยังต้องยืนยัน ไม่เปลี่ยนให้กระสุนไปโดนคนอื่นโดยอัตโนมัติ
02
DEBUFF · ON PLAYER

Chilled

ลดเฉพาะความเร็วเคลื่อนที่ของผู้เล่นชั่วคราว

Move Speed −25%ระยะเวลา 4sRefresh · ไม่ Stack

วิธีรับมือ: ผู้เล่นยังเคลื่อนที่และต่อสู้ได้ตามปกติ ไม่บังคับให้มี Dispel

อ่านกติกาละเอียด · Chilled
  • ไม่ลด Attack Speed หรือ Cast Speed โดนซ้ำให้รีเฟรชเป็น 4 วินาที แม้มาจาก Mage หลายตัว ไม่ทบความแรง
  • แสดงไอคอน Debuff เวลาคงเหลือ และน้ำแข็งบาง ๆ รอบเท้า หมดเวลาแล้วลบการลดความเร็วและเอฟเฟกต์ทันที
  • เมื่อ Mage Reset Debuff ที่ติดผู้เล่นแล้วหมดตามเวลาปกติ ไม่ล้างก่อนกำหนดโดยอัตโนมัติ
COMBAT FLOW

เข้าระยะและมี LOS → ร่าย 1.5s → ปล่อยเวท → พัก 3s → ร่ายซ้ำ / ถูก Interrupt ใช้ช่วงพัก 2s แทน

Core dependency

การจบไฟต์

จุดเด่นที่ต้องการ: เปลี่ยนโจทย์ด้วยการย้ายพื้นที่ต่อสู้ การเคลียร์มอนปลายทางไว้ก่อนเป็นความได้เปรียบที่ยอมรับได้ ไม่เสกมอนมาทดแทน

AUTO ATTACK

Venom Bite

เข้าประชิดแล้วกัดเป้าหมายหนึ่งคน ดาเมจเบา ไม่มี Debuff

หน้าที่ของท่า: รักษาแรงกดดันประชิดระหว่างรอ Venom Pool

กติกาและค่าที่ยังไม่กำหนด
  • ใช้กับเป้าหมายที่มี Threat สูงสุดตามกติกาเลือกเป้าหมาย ไม่เปลี่ยนเป็นคนใกล้สุดโดยอัตโนมัติ
  • ไม่มี Poison DoT หรือ Chilled จากการกัด
  • ระยะ Auto-Attack ความถี่ และดาเมจจริงยังไม่ระบุในดราฟนี้ ไม่เติมค่าจากมอนตัวอื่น
  • หยุด Auto-Attack ระหว่างเตรียมพ่น Venom Pool และระหว่างถอย A → B
02
ACTIVE · GROUND HAZARD

Venom Pool

เตือนบนพื้นที่เป้าหมายยืน ก่อนสร้างบ่อพิษในจุดเดิม ผู้เล่นทุกคนที่ยืนในบ่อรับดาเมจเป็นช่วง ๆ เดินออกแล้วหยุดรับดาเมจ

ระยะใช้ ~4 Gridเตือน ~1.5sเส้นผ่านศูนย์กลาง ~2 Gridบ่ออยู่ ~5s

วิธีรับมือ: เดินออกจากวงเตือน จุดถูกล็อกตั้งแต่เริ่มใช้และไม่ตามผู้เล่น ไม่มีดาเมจระเบิดทันทีตอนบ่อเกิด

ตำแหน่ง การคิดดาเมจ และ Cooldown
  • ล็อกตำแหน่งเป้าหมายเมื่อเริ่มใช้ ต้องมี LOS ตอนเริ่ม ไม่เลือกจุดผ่านกำแพงหรือใน Safe Zone หลังเริ่มเตือนแล้ว ผู้เล่นหนีได้แต่บ่อยังเกิดที่เดิม
  • ระหว่างเตรียมพ่นหยุดเดินและหยุด Auto-Attack ไม่พ่นขณะเคลื่อนที่
  • เส้นผ่านศูนย์กลางบ่อ 2 Grid อายุประมาณ 5 วินาที Tick ทุก 1 วินาที โดยครั้งแรกหลังบ่อเกิด 1 วินาที ไม่มีดาเมจตอนเกิด
  • ออกจากบ่อแล้วหยุดรับดาเมจ ไม่มี Poison DoT หรือ Debuff ติดตัวต่อ Chilled เป็นสกิลของ Mage ไม่ใช่แมงมุม
  • ครั้งแรกหลังเริ่มสู้ประมาณ 4 วินาที ครั้งต่อไปประมาณทุก 10 วินาที นับจากบ่อครั้งก่อนเกิด
  • ช่วงต่อสู้ปกติ หากเป้าหมายนอกระยะให้เคลื่อนเข้าหาก่อน เมื่อพ่นจบกลับไปไล่โจมตี
  • ข้อความดราฟให้ผู้เล่นทุกคนในพื้นที่รับดาเมจ แต่เงื่อนไขสิทธิ์รับผลข้ามปาร์ตี้ยังต้องยืนยันกับ Dev
  • จุดอ้างอิงวัดระยะใช้และการตัดสินว่าอยู่ในบ่อ รวมถึง Tick ที่ตรงกับจังหวะบ่อหมดอายุ ยังต้องยืนยัน ไม่สรุปจำนวน Tick รวมแทนทีม

03
RETREAT · ONCE PER FIGHT

Retreat to B

เมื่อ HP เหลือ 60% หรือต่ำกว่า ถอยจากจุดเริ่ม A ไปจุดตั้งรับ B หนึ่งครั้งต่อไฟต์ ระหว่างทางยังโจมตีและฆ่ามันได้

HP ≤60%ไม่ฮีล / ไม่อมตะไม่ล้าง Threat

ทางเลือกผู้เล่น: เร่งปิดงานระหว่างถอย ไล่เข้าไปพร้อมรับมอนปลายทาง หรือเคลียร์ B ไว้ก่อน ถ้า B ว่าง แมงมุมยังถอยไปที่เดิมโดยไม่มีมอนทดแทน

เส้นทาง มอนปลายทาง และการพ่นพิษระหว่างถอย
  • A คือจุดเริ่ม Outdoor ข้างห้อง B คือจุดตั้งรับใกล้แท่นศิลา เดินอ้อมห้องตามเส้นทาง Walkable ที่กำหนด ทั้ง A เส้นทาง และ B ต้องอยู่ในขอบเขตต่อสู้เดียวกัน ตำแหน่งจริงต้อง Remap บนแผนที่ LD ล่าสุด
  • หากกำลังเตรียมพ่น ให้พ่นจบก่อนเริ่มถอย หากตายระหว่างร่ายยกเลิกตามปกติ
  • ระหว่างถอยหยุดกัด ไม่ไล่เป้าหมาย ยกเว้นหยุดเดินพ่น Pool เมื่อ CD พร้อม เป้าหมายอยู่ในระยะและมี LOS จากนั้นถอยต่อ ใช้ CD เดิม ไม่รีเซ็ตตอนเริ่มถอย
  • ถ้าเป้าหมายนอกระยะ ไม่ย้อนกลับไปหาเพื่อพ่น ถึง B แล้วกลับมาต่อสู้ตามปกติ ไม่ถอยรอบที่สอง
  • กองตั้งรับ B: Mage 1 + Melee 1 + Archer 1 ตั้งต้นรวมกันตามข้อสรุปเดิม ไม่เพิ่มธนูตามภาพที่ขัดกับข้อความยืนยัน
  • มอนที่ B ใช้ Aggro ปกติ ไม่เรียกทั้งห้องเข้าต่อสู้อัตโนมัติ หากผู้เล่นหรือปาร์ตี้อื่นเคลียร์ไว้แล้วจะไม่มีการเสกทดแทน
  • ผู้เล่นใกล้เคียงอาจติด Aggro ร่วมด้วย แต่เป้าหมายโจมตียังเป็นผู้มี Threat สูงสุด ระยะและสิทธิ์เข้าร่วมยังไม่กำหนด
  • Threat ค่อย ๆ ลดลงเป็นสมมติฐานสำหรับคุยกับ Core ยังไม่ยืนยันระบบจริงหรืออัตราลด ไม่ใช่การล้าง Threat ด้วย Retreat
COMBAT FLOW

เข้าประชิดและกัด → Pool แรก ~4s → กัดสลับ Pool → HP ≤60% ถอยไป B → ต่อสู้ต่อ

Active เมื่อผู้เล่นเข้าระยะตรวจจับ ไม่เรียกมอนใกล้เคียงเข้าต่อสู้อัตโนมัติ ไม่ไล่เข้า Safe Zone

การตาย / Reset

ตายหรือออกจากต่อสู้ ยกเลิกวงเตือนและลบบ่อของตัวนี้ หากไม่มี Target ที่สู้ต่อได้ ให้เริ่มกลับ A พร้อม Invincible + Regen ทันที ถึงจุดแล้ว Idle จน HP เต็ม ก่อนพร้อมสู้อีกครั้งและคืนสิทธิ์ Retreat

กรณี Leash ให้ออกจากต่อสู้และใช้ Reset ตามกติกากลาง อัตราฟื้น HP ระยะ Leash และกรณีเลือดเต็มก่อนเดินถึงยังไม่กำหนด การป้องกันระหว่าง Reset ไม่ใช้กับการถอยในไฟต์

รอตัดสินใจ

การรอที่ B มีสองดราฟ: A รอประมาณ 1 นาที / B อยู่จนถูกฆ่า ยังไม่เลือก โดยเฉพาะข้อยกเว้นต่อกติกาไม่มี Target แล้วกลับ A

Retreat Tell เพิ่มเติมยังเป็นข้อเสนอ ไม่ใส่เป็นสกิลที่ตกลงแล้ว ความถึกและตัวเลขสกิลเป็นค่าเริ่มต้นสำหรับเทสต์ ไม่ใช่ผล Balance

02

Crushing Strike

ง้างอาวุธแล้วฟันหนักเป้าหมายหนึ่งคน เมื่อทำดาเมจสำเร็จเพิ่ม Growing Fury หลังคิดดาเมจ

ระยะ ~1 Gridง้าง 1.5sพัก 1s

วิธีรับมือ: ถอยพ้นระยะก่อนโดนหรือรับด้วยสกิลป้องกันตามที่คลาสรองรับ Interrupt ท่านี้ไม่ได้

อ่านกติกาละเอียด · Crushing Strike
  • Cast Bar และอาวุธเรืองแสงแดง ระหว่างง้างหยุดเดินและ Auto-Attack ล็อกเป้าหมายตั้งแต่เริ่ม ไม่เปลี่ยนไปฟันคนอื่นกลางท่า
  • ตอนจบตรวจเป้าหมายเดิมยังอยู่ในระยะและโจมตีได้ สร้างดาเมจครั้งเดียวสูงกว่า Auto-Attack พลาดไม่ทำดาเมจและไม่เพิ่ม Stack
  • หลังฟันพัก 1 วินาที ไม่ปล่อย Auto-Attack ซ้อนทันที ไม่มี Frontal / AoE / Knockback / Stun
  • เริ่มเมื่อเป้าหมายอยู่ในระยะประชิดเท่านั้น ถ้านอกระยะให้เข้าหาก่อน ครั้งแรกหลังเริ่มสู้ 5 วินาที ซ้ำทุกประมาณ 10 วินาทีหลังท่าก่อนจบ
03
BUFF · ON MONSTER

Growing Fury

Crushing Strike ที่ทำดาเมจสำเร็จทำให้ Crushing ครั้งถัดไปแรงขึ้น

+10% Base / Stackสูงสุด 5 Stack = +50%

วิธีรับมือ: หลบ Crushing ให้พลาดเพื่อไม่ให้เพิ่ม Stack ครั้งนั้น การเปลี่ยนเป้าหมายไม่ล้าง Buff

อ่านกติกาละเอียด · Growing Fury
  • เริ่มสู้ด้วย 0 Stack เพิ่ม 1 Stack หลังคิดดาเมจ Crushing ที่สำเร็จ ไม่เพิ่มก่อนคิดดาเมจครั้งเดียวกัน
  • สูตร Crushing = Base × (1 + 0.10 × Stack ก่อนโจมตี) คิดแบบบวกจากฐาน ไม่ทบคูณ
  • Auto-Attack และ Thunderous Roar ไม่เพิ่ม Stack และไม่แรงขึ้นตาม Buff
  • แสดงไอคอนและจำนวน Stack บนมอน คงตลอดไฟต์รวมตอนเปลี่ยนเป้าหมายหรือก้าวหลบ ล้างเมื่อตายหรือออกจากต่อสู้
  • ไม่มี Debuff บนผู้เล่น และไม่บังคับสลับแทงค์

ฮีลปกติ

ร่ายฮีลเป้าหมายเดี่ยว เป็นเครื่องมือหลักในการประคองเลือด

ฮีล 2–7% Max HPCD 2s

การใช้งาน: ช่วยผู้เล่นมีชีวิตในปาร์ตี้ที่ผูกไว้ ต้องอยู่ในระยะและมี LOS

อ่านกติกาละเอียด · ฮีลปกติ
  • ไม่ฮีลปาร์ตี้อื่นหรือ Follower อื่น ฮีลตนเองได้ด้วยสกิลและ Cooldown เดียวกัน
  • เลือกผู้เล่นในระยะและ LOS ก่อน เน้นสัดส่วน HP ต่ำและกำลังรับดาเมจ หากใกล้เคียงกันเลือกผู้กำลังรับการโจมตี / Highest Threat ไม่ฮีลคนเลือดเต็มหรือสลับเป้าถี่ตาม HP ขยับเล็กน้อย
  • ตั้งใจร่ายแล้วร่ายต่อ เว้นแต่ต้องหลบ เป้าหมายตาย หรือเงื่อนไขไม่ผ่าน สูตรเลือกเปอร์เซ็นต์ ระยะ และ Cast Time ยังไม่กำหนด

EMERGENCY HEAL · AUTO

ฮีลฉุกเฉิน

ฮีลเดี่ยวทันทีโดยอัตโนมัติเมื่อผู้เล่นเข้าเกณฑ์วิกฤต

Trigger HP <20%ฮีล 70% Max HPCD 10 นาที

การใช้งาน: ใช้เป็นเครื่องประคองยามฉุกเฉิน การเรียก NPC ใหม่ไม่รีเซ็ตสกิล

อ่านกติกาละเอียด · ฮีลฉุกเฉิน
  • ต้องผ่านระยะและ LOS เช่นเดียวกับฮีลปกติ CD 10 นาที ไม่ใช่ 10 วินาที ข้อความดราฟกำหนดไม่รีเซ็ตทุกกรณี รวมเรียก NPC ใหม่
  • ขอบเขต / Key เก็บ CD และการใช้ฮีลฉุกเฉินกับตนเองต้องตกลงกับ Dev ไม่ใช้ Recall เป็นทางล้าง CD

Follow Indicator

แสดงให้ผู้เล่นรู้ว่า Echo กำลังติดตามอยู่

การใช้งาน: เป็นสถานะบอกการติดตาม ไม่มี Positive Effect ต่อ Stat

  • ไม่เพิ่ม Stats จากการมีไอคอนติดตาม จำนวน Echo ต่อปาร์ตี้และการโอนผู้เล่นหลักยังไม่กำหนด
05
RECOVERY · INTERACT

ฟื้นตัว

เมื่อ HP เหลือ 1% ถอนจากต่อสู้แล้วฟื้นเต็ม ผู้เล่นกดค้าง Interact เพื่อเร่งได้

ฟื้นปกติ 40sช่วยต่อเนื่องเต็มรอบ 10sอัตราช่วย 4 เท่า

การใช้งาน: หยุดกดแล้วกลับอัตราฟื้นปกติ เก็บความคืบหน้าเดิม หลายคนช่วยไม่ทบอัตรา

อ่านกติกาละเอียด · ฟื้นตัว
  • HP ไม่ลดต่ำกว่า 1% เมื่อเข้าเกณฑ์นี้ Monster ไม่สามารถเลือกเป็นเป้าโจมตีได้ แต่กติกานี้ยังไม่ยืนยันภูมิคุ้มกัน AoE หรือ DoT เดิม
  • 4 เท่าของอัตราปกติ เท่ากับเพิ่มอัตรา 300% ไม่ใช่เพิ่ม 400% ช่วยตั้งแต่เริ่มจนจบจึงใช้ 10 วินาที
  • ดราฟระบุถ้าไม่มีผู้เล่นรอในบริเวณประมาณ 11 Grid ระหว่างฟื้น ให้กลับจุดแรกใน Safe Room ยังต้องระบุวัดจากใคร สมาชิกใดใช้ตรวจ และช่วงผ่อนผัน
DECISION PRIORITY

หลบอันตรายใต้ตัว → ฮีลฉุกเฉิน → ฮีลปกติ → จัดตำแหน่ง → ติดตาม

Position / Dodge

อยู่ด้านหลังหรือข้าง ไม่เดินเข้าหามอนที่ยังไม่ Aggro ขยับหามุมฮีลใกล้ ๆ โดยไม่ฝ่าอันตรายหรือทิ้งกลุ่มเพื่อคนแยกไกล ยอมยกเลิกฮีลเพื่อหลบจุดปลอดภัยที่เดินถึง มี Reaction Time ปรับได้ ไม่รู้สกิลล่วงหน้าหรือรับประกันหลบสำเร็จ ไม่มีวาร์ป / อมตะพิเศษเมื่อหลบไม่ได้

Follow / Quest

เว้นระยะจากผู้เล่นหลัก ไม่ยืนซ้อนตัว ระหว่างสู้ให้ตำแหน่งฮีลและการหลบสำคัญกว่าเดินตาม หลังสู้ฮีลด้วยข้อจำกัดเดิมแล้วกลับติดตาม นำทางไปแท่นบูชาได้ แต่ไม่กดศิลา เก็บของ เปิดแพ็ก หรือทำเควสแทน ไม่วาร์ปตามแก้ทางตันกลางต่อสู้ จำนวนต่อปาร์ตี้ / การผูก / คนหลักหลุดเกม ตาย หรือปาร์ตี้ยุบยังรอยืนยัน

CATACOMB 2F · บอสท้ายชั้น

ผู้ถือตะเกียงแห่งสุสาน

ชื่อเสนอ · หลอดเลือดเดียวต่อเนื่องตลอดสองเฟส

สำหรับ Dev · ค่าเทส POC

Max HP 24,000

Damage · ฟันปกติ 80 · กวาดตะเกียง 144 ต่อคน · วงไฟ 28 ต่อคนต่อวินาที นาน 4 วินาที (รวม 112 หากยืนครบ)

Damage คือ HP ที่ผู้เล่นอ้างอิงเลือด 1,000 เสียหลังหักป้องกัน ปรับค่าอีกครั้งหลังเทสในเกม

เฟส 1 · หลบกรวย

ฟันประชิดคนที่มี Threat สูงสุดระหว่างรอท่ากวาด เมื่อตะเกียงยกขึ้น บอสล็อกทิศและเตือน 1.5 วินาทีก่อนกวาดกรวย 90° ระยะ 3 Grid ผู้เล่นเดินหลบออกข้างได้

เฟส 2 · HP เหลือ 12,000 หรือต่ำกว่า

บอสจบท่าปัจจุบันแล้วชูตะเกียง 2 วินาที เปลี่ยนเฟสครั้งเดียว จากนั้นทุกครั้งที่กวาดจบจะวางวงไฟใต้คนที่อยู่ไกลที่สุด วงล็อกกับพื้นและเตือน 2 วินาที ให้เดินออกก่อนเริ่มเสียเลือด

เวลาเป้าหมาย POC ประมาณ 2 นาที เมื่อปาร์ตี้ทำดาเมจรวมเฉลี่ย 200 HP/วินาทีตลอดไฟต์

กติกากลาง / Core

Default Monster Reset · ใช้กับมอนศัตรูทุกตัว
  • เมื่อไม่มี Target ที่ต่อสู้ต่อได้ เริ่มกลับจุดเกิดพร้อม Invincible + Regen ทันทีตั้งแต่เริ่มกลับ ถึงแล้ว Idle ฟื้นต่อจน HP เต็มจึงพร้อมสู้อีกครั้ง ฟื้นแบบค่อยเป็นค่อยไป ไม่เติมเต็มทันที
  • ไม่ไล่หรือโจมตีเข้า Safe Zone ระยะและเงื่อนไข Leash อัตราฟื้น HP การตรวจ Target เข้าไม่ถึง และกรณี HP เต็มก่อนเดินถึงยังต้องตกลงกับ Core
  • การถอยในไฟต์ของ Tarantula ไม่ใช่ Reset จึงไม่ฮีลหรืออมตะ ส่วน Echo ใช้กติกาฟื้นตัวของ Follower แยกต่างหาก
Point-to-click / True Projectile / หน่วยวัด
  • การควบคุมปัจจุบันคือ Point-to-click (คลิกตำแหน่งเพื่อเคลื่อนที่) ตามการแก้ล่าสุด 4 พฤศจิกายน 2026 ส่วน Concurrent + Server Stability โดยพยายามให้ความรู้สึกตอบสนองที่ดี ไม่ใช่การยืนยันระบบเครือข่ายหรือผล Benchmark
  • การเลือกเส้นทาง การเลือกเป้าหมาย ปุ่มที่ใช้ การยกเลิกคำสั่งเดิน และการเดินระหว่างร่ายยังรอยืนยันกับ Core จุดหมายที่พ้นวงไม่ได้ยืนยันว่าเส้นทางเดินจะปลอดภัยหรือออกทัน ค่าระยะและเวลาสกิลเดิมยังไม่เปลี่ยน
  • เลี่ยง True Projectile ที่จำลองตำแหน่งและการชนต่อเนื่อง ภาพการยิงไม่ถูกห้ามทั้งหมด แต่รูปแบบ Hit / Range / LOS / การยกเลิกยังต้องให้ Dev ยืนยัน
  • Grid ไม่ได้แปลงเป็นเมตรโดยอัตโนมัติ จุดวัดจากกึ่งกลาง / ขอบ Collision ยังไม่ตกลงทุกท่า แยกเส้นผ่านศูนย์กลางบ่อ 2 Grid กับรัศมี Roar 5 Grid
Roster ที่ยังไม่มีสเปกสกิลยืนยัน

Rat / Bat / Wisp เคยมีการกล่าวถึง Asset แต่บทบาทและชุดสกิลยังไม่ล็อก จึงไม่สร้างท่า Level หรือสถานะลงแพ็กเพิ่มโดยอัตโนมัติ การมีภาพไม่ยืนยันว่ามี Combat implementation แล้ว
