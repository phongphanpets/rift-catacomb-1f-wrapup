◇Core Direction — ข้อสรุปจาก Quick meet

ตาม Log GD Aon เวลา 14:23 ทีมใช้กรอบ 1.Concurrent / 2.Realtime Responsive / 3.Server Stability (รวม Security) และเลือก 1 + 3 พร้อมพยายามให้รู้สึกตอบสนองแบบ 2 (“fake 2”)

  • เคลื่อนที่ด้วย WASD; ยังไม่ยืนยัน Free Aim, การร่ายขณะเดิน หรือ Dodge action
  • เลี่ยง True Projectile ที่ต้องติดตามตำแหน่งและตรวจ Collision/Condition แบบ Real time ต่อเนื่อง เช่น Object มาขวางกระสุนระหว่างเดินทาง หรือเปลี่ยนทิศ/ความเร็วแบบ Skillshot
  • ไม่ใช่คำสั่งห้ามภาพลูกธนู/เวททุกแบบ. Mage/Archer ต้องแยกภาพที่เห็นออกจากกติกาคิดผลโจมตี แล้วตกลงจังหวะตรวจ Range/LOS/ยกเลิกกับ Core
  • Pool / Frontal / Roar / Retreat ไม่ต้องพึ่ง True Projectile โดยตัวกติกา แต่ยังไม่มีผลยืนยัน Server Performance
  • CS/RO/WoW/FFXIV เป็นตัวอย่างอธิบายใน Log ประชุม ไม่ใช่ผลตรวจสถาปัตยกรรมหรือ Benchmark ของเอกสารนี้
◇Common Zone — Art / Blockout ที่ใช้คุยต่อ

ภาพนี้เสนออารมณ์และสถาปัตยกรรม ไม่ล็อก Final Art Direction, Scale หรือความพร้อม Asset. ภาพ Portal ใน Concept ก่อนหน้าถูกแทนเฉพาะทางเข้า Catacomb ด้วยบันไดตาม Blockout ด้านล่าง

Church → Threshold → ลานกลาง Hub → บันไดด้านตะวันตกเฉียงใต้ → ชานพักล่าง → Safe Room ทางเข้า 1F เดิม. ตำแหน่งหัวบันได/การต่อเป็น Working Proposal ไม่ใช่ภูมิศาสตร์ Canon หรือ Unity Scene; บันไดไม่ได้เปลี่ยนชื่อชั้นเป็น B1

Master Vesper ยังเฝ้าประตู ให้บริบทก่อนออกงานและรับฟังหลังกลับ. NPC ทางเข้า/Checkpoint ยังทำหน้าที่รับ–ส่งเควสเดิม; การกลับ Hub เป็น Optional

◇LD Layout ล่าสุด — ฐานสำหรับงานต่อ

ภาพ LD นี้ได้รับความเห็นชอบเป็น Working Base ล่าสุด. ภาพเก่าในส่วน Map/Quest Route ยังคงไว้เพื่ออ้างองค์ประกอบ ไม่ใช่พิกัดใหม่. สี/ลูกศร/ขนาด/ความสูงยังไม่มี Legend ที่ยืนยัน จึงไม่สรุป One-way, Jump, LOS ข้ามระดับ หรือ Capacity จากภาพ

กฎพื้นแตกเป็น Block ไม่ใช่ทางกระโดดยังคงอยู่; ภาพใหม่ไม่ยืนยันว่าแถบดำคือ Block เดิมหรือทางลอด. ต้องติดชื่อ Safe Room/Checkpoint/ห้องท้ายและเทียบ Route กับ LD

◇Mob Pack / Activity — ใช้ข้อมูลเดิมต่อ ไม่เริ่มใหม่

ภาพ Placement เดิมมี 4 วงพร้อมป้ายจำนวนคน อยู่แล้ว: P1 4–5, P2 6–8, P3/P4 8+. เป็นคำแนะนำ ไม่ใช่ Minimum Entry หรือผล Balance

จุด B ของแมงมุมในภาพท้ายเห็น Archer 2 แต่ข้อความยืนยันคือ Mage 1 + Melee 1 + Archer 1. คงข้อความที่ยืนยัน ไม่เพิ่มตัวที่สองเอง

Rite / Lost Chamber มี Candidate Placement แล้วบนผังเก่า แต่ต้องตรวจใหม่บน Layout LD ล่าสุด ไม่ถ่าย Pixel pins มาทับ. ทั้งคู่ Optional ไม่เปลี่ยน Main Quest และยังไม่พิสูจน์ว่าลดการกระจุกได้

Lore / บทนำ

Rift of Catacomb — บทนำสู่ Rift of Death

Narrative Draft — เรื่องเล่าฉบับขยาย: โทน Cosmic Horror / Lovecraftian รายละเอียด บทสนทนา และเหตุการณ์ที่เพิ่มเป็นข้อเสนอให้ตรวจอ่าน ยังไม่ล็อกเป็น Canon หรือเพิ่มเป็นสิ่งที่เกมต้อง Implement

Rift of Catacomb เป็นสถานที่ย่อยของ Rift of Death และทำหน้าที่เป็นบทนำให้ผู้เล่นเริ่มทำความรู้จักกับมัน ขณะเข้ามาที่นี่ ผู้เล่นยังไม่รู้ว่า Rift of Death คืออะไร หรือเกิดอะไรขึ้นที่นั่น

คำถามที่บทนำตั้งใจเก็บไว้คือ Rift of Death คืออะไร และเกิดอะไรขึ้นที่นั่น? เรื่องเล่าด้านล่างเสนอให้ผู้เล่นเริ่มสงสัยผ่านสุสาน รายชื่อ และความทรงจำ ไม่ใช่เฉลยคำตอบนั้น

◇สุสานที่จดจำเรา — The Sepulchre That Remembers

ห้องของผู้ยังไม่ถูกลืม

ในห้องรับภารกิจของ Master Vesper มีเสียงกระดาษพลิกอยู่เสมอ แม้บางขณะมือของเขาจะวางนิ่งบนโต๊ะ และไม่มีใครเห็นว่าหน้ากระดาษเหล่านั้นเคลื่อนไหว

เหล่ายมทูตฝึกหัดเคยคิดว่าเป็นลมจากประตูวงเวท จนวันหนึ่งมีผู้สังเกตว่าเปลวเทียนไม่เคยเอนตามเสียงนั้น

Vesper ตรวจรายชื่อผู้ตายทีละบรรทัด เขาแยกบันทึกที่ถูกต้องออกจากบันทึกที่ต้องส่งกลับไปตรวจใหม่อย่างใจเย็น แต่บางหน้าถูกพับคว่ำทันทีที่เปิดพบ ไม่มีตราปฏิเสธ ไม่มีคำอธิบาย และไม่มีใครได้รับอนุญาตให้คัดสำเนา

งานจาก Catacomb มักมาในหน้ากระดาษประเภทหลัง

เมื่อถูกถามว่าสถานที่นั้นอยู่ที่ใด Vesper เพียงตอบว่ามันเป็นส่วนหนึ่งของ Rift of Death ชื่อซึ่งไม่ช่วยให้ผู้ถามเข้าใจมากขึ้น แผนที่ระบุตำแหน่งสุสานได้ ประตูวงเวทพาไปถึงได้ แต่ถ้อยคำอธิบายว่า Rift แห่งนั้นคืออะไรกลับไม่อยู่ในเอกสารที่มอบให้

ก่อนส่งผู้ฝึกหัดออกเดินทาง เขาให้คำเตือนสั้นกว่าคำอธิบายภารกิจเสียอีก

“ถ้าพบชื่อที่จำไม่ได้ จงนำกลับมา ถ้าพบชื่อที่จำได้ จงตรวจให้แน่ใจก่อนว่าเจ้าจำมันมาจากที่ใด”

ชื่อบนหิน

จากทางเข้า Catacomb ดูไม่ต่างจากสุสานที่ถูกละทิ้ง กำแพงชื้น เสาที่แตก และแท่นศิลาซึ่งไม่มีผู้ดูแลมานาน สิ่งที่ทำให้คนชะงักไม่ใช่ความเก่าแก่ หากเป็นร่องรอยการซ่อมแซม บนผนังบางช่วงมีอิฐใหม่อุดอยู่เหนือหินที่ผุจนแทบเป็นดิน ราวกับยังมีใครกลับมาดูแลสถานที่ซึ่งไม่มีผู้ใดอ้างว่าเคยกลับมา

ป้ายชื่อหลุดจากหลุมกระจัดกระจายอยู่ตามทาง บางแผ่นอ่านได้ชัด บางแผ่นถูกขูดจนลึกถึงเนื้อหิน แต่รอยขูดไม่ได้ทำลายตัวอักษรทุกส่วน มันหยุดตรงพยางค์สุดท้ายบ่อยเสียจนยากจะเชื่อว่าเป็นความเสียหายโดยบังเอิญ

ผู้สำรวจคนหนึ่งคัดชื่อจากแผ่นหินลงสมุด ครั้นเงยกลับไปตรวจ เขาพบว่าตนเองเว้นช่องว่างไว้กลางชื่อ เขายังจำได้ว่าขณะเขียนรู้สึกมั่นใจเพียงใด แต่ไม่อาจจำเสียงของพยางค์ที่หายไปได้อีก

คืนนั้นเขาเขียนกำกับไว้ว่าเหนื่อยล้า เช้าวันถัดมาเขาจำไม่ได้ว่าเหตุใดจึงใช้ลายมือของคนอื่นเขียนคำกำกับนั้น

เรื่องเช่นนี้ไม่ปรากฏในรายงานทุกฉบับ บางคนกลับออกมาพร้อมป้ายชื่อครบและคำอธิบายธรรมดา บางคนยืนยันว่าทุกแผ่นว่างเปล่าตั้งแต่แรก ความไม่ตรงกันเหล่านั้นถูกเก็บไว้คู่กัน โดยไม่มีผู้ตรวจคนใดขีดฆ่าฉบับหนึ่งเพื่อรับรองอีกฉบับ

สิ่งที่แสงทำให้เห็น

การจุดไฟแท่นศิลาควรเป็นงานเรียบง่าย แสงเผยพื้นทาง เผยชื่อบนหิน และทำให้ผู้ที่อยู่ด้วยกันเห็นใบหน้าของกันและกันอีกครั้ง

แต่มีผู้กลับมารายงานว่าหลังไฟติด เขานับเงาบนผนังได้มากกว่าคนที่ยืนอยู่ตรงนั้น เขายกมือขึ้นเพื่อหาว่าเงาใดเป็นของตน เงาส่วนใหญ่ยกตาม มีเพียงเงาหนึ่งที่ยกมือไว้ก่อนแล้ว

เมื่อเล่าเรื่องนี้ซ้ำ เขากลับไม่แน่ใจว่าเห็นมันยกก่อน หรือเพียงเผลอมองเงาของเพื่อนร่วมทาง เรื่องจึงจบลงด้วยการหัวเราะ ไม่มีใครอยากเป็นคนแรกที่ขอให้ดับไฟเพื่อนับใหม่

วิญญาณที่วนเวียนในสุสานไม่ได้ให้คำตอบชัดเจนไปกว่าเงา เสียงคร่ำครวญบางช่วงฟังคล้ายการพยายามออกเสียงชื่อเดิมซ้ำ ๆ ขณะที่ร่างกระดูกในห้องชั้นในยังยกอาวุธขึ้นราวกับทำหน้าที่ตามคำสั่งซึ่งผู้สั่งไม่อยู่แล้ว

พวกมันเฝ้าสิ่งใด ป้องกันใคร หรือเพียงทำสิ่งสุดท้ายที่จำได้ต่อไป ไม่มีผู้สำรวจคนใดมีหลักฐานพอจะตอบ

บันทึกซึ่งไม่มีผู้เขียนรับรอง

ในสำเนาบันทึกเก่าฉบับหนึ่ง มีรายชื่อ วันที่ และช่องระบุผู้รับศพเป็นระเบียบ จนถึงหน้าที่หมึกทุกบรรทัดจางลงพร้อมกัน ไม่ใช่เพราะกระดาษถูกน้ำ เพราะเส้นตารางและคราบนิ้วตรงขอบหน้ายังชัดอยู่

ใต้ตารางนั้นมีข้อความเขียนเบียดลงไปด้วยแรงกดจนกระดาษเกือบขาด

“เรายังนับได้ว่ามีผู้ตายเท่าไร แต่ไม่รู้แล้วว่าต้องเรียกพวกเขาว่าอะไร”

หน้าถัดไปไม่มีกฎพิธี ไม่มีแผนที่ และไม่มีคำอธิบายเหตุการณ์ มีเพียงรายชื่อที่เขียนซ้ำทีละคน ลายมือเปลี่ยนไปหลายครั้ง แต่ทุกแบบพยายามเลียนเส้นอักษรของบรรทัดแรก ราวกับผู้คัดเชื่อว่าการทำให้ชื่อเหมือนเดิมจะเพียงพอให้สิ่งอื่นกลับมาเหมือนเดิมด้วย

บันทึกไม่ได้บอกว่าความพยายามนั้นสำเร็จหรือไม่ หน้าสุดท้ายถูกฉีกออกก่อนนำส่ง และไม่มีใครรู้ว่าเป็นผู้ส่งหรือผู้รับที่ฉีกมัน

Vesper ไม่รับรองข้อสันนิษฐานว่าการลืมชื่อทำให้วิญญาณติดค้าง เขาตรวจลายมือ ตรวจตราประทับ แล้วเก็บสำเนาไว้ในหมวดที่ไม่เคยส่งคืนให้ผู้ฝึกหัดอ่าน หากถูกถามถึงหมวดนั้น เขาจะกลับไปตรวจความมั่นคงของประตูเสียก่อน

สิ่งที่อยู่เลยชื่อของสถานที่

ลึกเข้าไป งานของผู้เดินทางยังมีขอบเขตที่เข้าใจได้ รวบรวมสิ่งที่ขาดหาย จุดไฟ เปิดเส้นทาง และเผชิญหน้าผู้เฝ้าสุสาน งานเหล่านี้ทำสำเร็จได้ รายชื่อส่งคืนได้ และคนที่กลับมามีสิทธิ์บอกว่าตนเสร็จภารกิจแล้ว

แต่ไม่มีเอกสารฉบับใดระบุว่าการโค่นผู้เฝ้าสุสานจะตอบคำถามเรื่อง Rift of Death ไม่มีหลักฐานว่ามันเป็นผู้สร้างสถานที่นี้ หรือว่าประตูที่มันเฝ้ามีไว้ป้องกันคนนอกไม่ให้เข้า

ผู้กลับออกมาบางคนไม่ถามถึงเรื่องนั้นอีก พวกเขาเพียงขอให้ Vesper อ่านชื่อผู้รับภารกิจให้ฟัง ก่อนตรวจว่าชื่อที่ได้ยินยังตรงกับชื่อที่จำได้

และในห้องรับภารกิจ เสียงกระดาษยังพลิกอยู่ต่อไป

แม้คราวนี้สมุดทุกเล่มบนโต๊ะจะถูกปิดไว้แล้ว

คำถามที่ตั้งใจเก็บไว้ Rift of Death คืออะไร และเกิดอะไรขึ้นที่นั่น ยังไม่เฉลยในบทนำนี้
สิ่งที่ยังไม่ล็อกเป็น Canon ต้นกำเนิด Rift เหตุการณ์จริงในอดีต ผู้ก่อเหตุ และรูปแบบความสัมพันธ์ทางกายภาพระหว่างพื้นที่ เรื่องเล่าข้างต้นไม่ยืนยันคำตอบเหล่านี้

สองแถวท้ายไม่ใช่สิ่งเดียวกัน: คำถามของผู้เล่นเป็น Mystery ที่ตั้งใจเก็บไว้ ส่วนรายละเอียดที่ทีมยังไม่ได้ให้เป็นข้อมูลรอยืนยันสำหรับผู้เขียน ไม่ใช่ Canon ลับที่ถูกกำหนดแล้ว

◇Vesper และภารกิจของผู้เล่น

ตาม Lore ที่มีอยู่ Master Vesper เป็นยมทูตผู้ดูแลห้องรับภารกิจในมิติระหว่างโลกคนเป็นกับความตาย เขาตรวจบันทึกผู้ตาย มอบหมายงาน และคอยรักษาสมดุลของประตู จึงไม่ทิ้งหน้าที่ออกเดินทางไปกับผู้เล่น

Echo of Vesper เป็นแนวทางตัวแทนช่วยเหลือผู้เล่นที่คุยไว้ โดยไม่ต้องพาตัวจริงออกจากจุดเฝ้าประตู ไม่ได้หมายความว่า Vesper เป็นผู้สร้าง Rift หรือรู้คำตอบทุกอย่างเกี่ยวกับเหตุการณ์ใน Rift of Death

Lore ส่วนนี้ให้บริบท ไม่เพิ่มเงื่อนไข Quest หรือเปลี่ยนผู้ให้ภารกิจใน Spec เดิม และไม่ยืนยันว่า NPC ทางเข้า / Checkpoint คือ Vesper ทั้งสองจุด

  • ข้อมูลเดิมที่ใช้: Lore ของ Master Vesper และ Quest / Activity ที่มีอยู่ โดยคงสถานะร่างและข้อขัดกันเดิม
  • ขอบเขตการตรวจ: ยังไม่ได้เปิดเอกสาร Present รอบก่อนในงานนี้ จึงไม่อ้างว่าได้ถอดเนื้อหาหรือยืนยันว่ารายละเอียดตรงกับรอบนั้นทั้งหมด

◇กรอบก่อนเริ่ม — เราจำลองอะไร

ใช้ Cognitive Walkthrough เป็นแกนตรวจการตัดสินใจ และ MDA เป็นเลนส์อ่านประสบการณ์ เป็นการประยุกต์สำหรับงานนี้ ไม่ใช่ชื่อ Framework สำเร็จรูปหรือโมเดลทำนายผู้เล่น

  • Cognitive Walkthrough: ตั้งเป้าหมาย ลำดับการกระทำ และความรู้เดิม แล้วถามว่า “รู้ว่าต้องทำไหม / เห็นทางเลือกไหม / เชื่อมทางเลือกกับเป้าหมายได้ไหม / เข้าใจผลลัพธ์ไหม” วิธีนี้เป็นการตรวจแบบจากเอกสาร ไม่ทดแทนคนเล่นจริง ดู Lewis & Rieman, Chapter 4
  • MDA: แยกกติกา (Mechanics), พฤติกรรมที่อาจเกิดจากการเล่น (Dynamics) และประสบการณ์ที่ต้องการ (Aesthetics) เพื่อไม่เอาเจตนาไปเขียนเป็นผลสำเร็จ ดู Hunicke, LeBlanc & Zubek — MDA

ขอบเขตการประยุกต์: ยังไม่มีหน้าจอ Quest / Interact หรือ Combat Demo ให้ตรวจ จึงเดิน “การกระทำระดับเป้าหมาย” ไม่ใช่ตรวจตำแหน่งปุ่มจริง ส่วนการแตกทางเลือกและสถานการณ์หลายปาร์ตี้เป็นส่วนเสริมของ Codex Sim ไม่ใช่ผลจากงานวิจัยทั้งสองชิ้น

วิธีอ่านแต่ละช่วง: เป้าหมาย → ข้อมูลที่มีหรือยังขาด → ทางเลือก → ผลตาม Spec → ประสบการณ์ที่อาจเกิด → จุดสะดุด ทั้งหมดใช้ Quest / Combat / Activity Draft เป็นแหล่งกติกา

◇เดินสถานการณ์ — จากทางเข้าถึงผู้เฝ้าสุสาน

ช่วง ทางเข้า — งานที่เข้าใจได้ แม้โลกยังไม่เข้าใจ

ปาร์ตี้เข้าจุดปลอดภัยและคุย NPC เป้าหมายแรกไม่ใช่ไขปริศนา Rift of Death แต่เลือกภารกิจที่ทำตรงหน้าได้ หากหน้ารับเควสสื่อชัด พวกเขาอาจรับทั้งชุดแล้วออกสำรวจ หากเห็นเพียงเควสเดียวก็อาจรับแค่นั้น ซึ่งระบบอนุญาต แต่ภายหลังยังต้องกลับมารับและส่งที่เหลือ

ช่วง โซนฟ้าฝั่งซ้าย — เลือกทำงานซ้อนกัน

ในภาพสำหรับทีมมีศิลาซ้าย ป้ายชื่อ และผี แต่ไม่ใช่ Minimap ที่รับรองว่าผู้เล่นจะเห็นทั้งหมด หากข้อมูล Quest บอกจุดหมายพอ ปาร์ตี้อาจไปศิลาก่อนตาม Route แนะนำ หรือเริ่มล่าผีระหว่างสำรวจแทน ผี Passive จึงไม่ควรเปิดการต่อสู้เพียงเพราะเดินผ่าน

เมื่อเลือกตีผี เครดิต Kill กับของดรอปทำควบคู่กันได้ แต่ของเควสต้องกดเก็บเอง สมาชิกที่ยืนใกล้พอและมีเควสจึงค่อยได้รับสิทธิ์ตามกติกา ผลตาม Spec: แต่ละคนเก็บป้ายต่างจุด กดศิลาเอง และกลับ NPC ทางเข้าเพื่อส่ง ไม่ใช้การทำของเพื่อนแทน ประสบการณ์ที่เป็นไปได้: งานเดียวช่วยหลายเป้าหมาย หรือรู้สึกต้องวนเก็บซ้ำถ้าการนับรายคนไม่ชัด จุดสะดุด: Anchor ป้ายโซนฟ้าฝั่งซ้ายครบตามเควสหรือไม่ยังต้องตรวจ ดู กติกาเควส

ช่วง ไป Checkpoint — จากปลอดภัยสู่การอ่านท่ามอน

หลังส่งชุดแรกครบ ปาร์ตี้รับชุดถัดไป อ้อมทางขวาเพราะพื้นแตกเดินผ่านไม่ได้ ทำศิลาสองจุดและสู้ Skeleton ระหว่างทาง เมื่อพบกรวยฟันของดาบโล่ การออกข้างเป็นทางตอบตาม Spec; เมื่อจอมเวทกำลังร่าย การใช้กำบังหรือ Interrupt เป็นทางเลือกเมื่อคลาส / พื้นที่รองรับ ไม่ถือว่าทุกปาร์ตี้มีเครื่องมือขัดร่าย

หากทำทั้งหมดได้ พวกเขาเปิด Checkpoint รายคนแล้วคุย NPC เพื่อส่งชุด ไม่ใช่แค่เดินผ่านแล้วนับเสร็จ จุดสะดุด: คนที่ลืมเปิดจุดเกิดหรือส่งเพียงบางเควสจะมี Progress ต่างจากเพื่อน การแสดงสถานะจริงต้องตรวจ ไม่รับรองว่า Echo จะชดเชยการยืนรับดาเมจทุกท่าได้ ดู Combat / Echo

ช่วง โซนแดงฝั่งซ้าย — การไล่ตามที่ไม่ใช่คำตอบเดียว

ปาร์ตี้เริ่มชุดสำรวจชั้นในและพบ Tarantula หากสู้จน HP มันเหลือ 60% หรือต่ำกว่า มันถอยไป B ครั้งเดียวโดยยังรับดาเมจ พวกเขาไม่รู้ปลายทางล่วงหน้า อาจไล่ตามเพราะเลือดปาร์ตี้ยังดี หรือหยุดดูเส้นทางเพื่อไม่ลากการต่อสู้เข้าไปหาอีกกอง

หาก B ยังมีมอนอยู่ กลุ่ม Mage + Melee + Archer เริ่มรวมกันอยู่ตาม Draft การ Priority Elite / Cleave Adds เป็นเพียงแนวทางที่อยากลอง ไม่ยืนยันว่า Skill คลาสทำได้จริง หาก B ถูกเคลียร์ไว้ การตามไปเจอจุดว่างก็เป็นข้อได้เปรียบที่ยอมรับ ไม่เสกมอนมาชดเชย จุดสะดุด: การมองเห็นการถอยและ Pool ท่ามกลางมอนหลายตัว รวมถึง Aggro Link ยังไม่ผ่าน Demo ดู Skull Tarantula

ช่วง ทางแยก — จะสู้ต่อ หรือสำรวจเรื่องที่ถูกลืม

หากพบ Lost Chamber ในโซนฟ้าและอ่านคำใบ้ได้ ปาร์ตี้อาจแวะตรวจบันทึกโดยไม่ต้องสู้เพิ่ม ถ้าประตูเปิดจากคนก่อน พวกเขาอาจได้ประสบการณ์ “พบห้อง” แต่ไม่ได้แก้ปริศนาเอง ส่วน Optional Rite ในโซนแดงให้เลือกเตรียมพื้นที่และเรียกคนก่อนเริ่ม แต่ยังไม่ทราบว่าจุดจริงจะถูกพบเมื่อไร

ผลตาม Draft: ข้ามทั้งคู่ได้ ไม่ขวาง Main Quest; Rite จบเมื่อฆ่ามอนและปิดผนึกครบ ไม่บังคับแบ่งหน้าที่ขณะมอนยังอยู่ จุดสะดุด: ฆ่ามอนก่อนแล้วค่อยปิดผนึกอาจง่ายกว่าเสมอ และจุดกิจกรรมเดียวที่น่าสนใจที่สุดอาจดึงคนมากระจุกแทนกระจาย ดู Optional Activities

ช่วง กลับ Checkpoint — สิทธิ์เข้าบอสเป็นรายคน

เมื่อแต่ละคนส่งชุดสำรวจครบ จึงรับ Fall of the Gravewarden รับตราและใช้ที่ผนึกหน้าห้องบอสเอง คนที่ Quest ยังไม่ถึงไม่ควรถูกพาข้ามเงื่อนไขเพียงเพราะหัวหน้าปาร์ตี้เปิดแล้ว

ผลตาม Spec: สิทธิ์เข้าเฉพาะตัวคงอยู่เมื่อตาย; การรับเควสหรือใช้ตราไม่สร้างบอสใหม่ จุดสะดุด: บอสอาจกำลังถูกสู้หรือยังไม่เกิด การรอจริงขึ้นกับ Spawn / Respawn ที่ยังไม่กำหนด ไม่จำลองว่าทุกปาร์ตี้จะพบห้องพร้อมสู้ และไม่ใช้ชุดสกิล Large Skeleton Elite แทน Boss Spec ที่ยังไม่ชัด ดู ประเด็นรอยืนยัน

ช่วง จบบทนำ — ความคืบหน้าชัด คำตอบของโลกยังไม่ครบ

หากร่วมสู้ผ่านเงื่อนไขเครดิตและปราบบอสสำเร็จ แต่ละคนกลับส่ง Checkpoint เพื่อจบ Quest Line ผู้ที่ตายค้างในพื้นที่อาจได้เครดิตตามเงื่อนไข ส่วนกลับเกิดนอกระยะไม่ได้ การชนะของปาร์ตี้จึงไม่รับรองว่า Progress ของทุกคนสำเร็จเท่ากัน

ในเชิง Narrative ตั้งใจให้จบภารกิจที่ทำได้ แต่ยังสงสัย Rift of Death เรื่องเล่าเรื่องชื่อและบันทึกอาจช่วยธีมนี้ได้เมื่อเลือกวิธีนำเสนอแล้ว ไม่ถือว่าทุกคนจะอ่าน Lore หรือรู้สึกหวาดกลัวเหมือนกัน

◇เส้นทางอื่นที่ต้องเดินคิดด้วย
สถานการณ์เปรียบเทียบ ผลที่รองรับ / จุดที่ยังไม่ทราบ สมมติฐานที่ถูกท้าทาย
รับเควสเดียว ไม่รับครบชุด ทำเควสนั้นได้ แต่ชุดถัดไปยังล็อกจนส่งที่เหลือ; ต้องตรวจว่ารู้ว่าขาดอะไรไหม ไม่ใช่ทุกคนจะอ่านหรือรับทุกเควส
อีกปาร์ตี้กำลังสู้ที่ B คนใกล้อาจเข้าร่วม Aggro; เป้าหมายยัง Highest Threat ไม่ใช่ใกล้สุด; ระยะ / Core ยังรอยืนยัน การถอยอาจไม่ใช่แค่เรื่องของปาร์ตี้ที่เริ่ม
B ถูกเคลียร์ก่อน Tarantula ยังถอย แต่ไม่มี Adds ทดแทน; Respawn ปกติยังไม่กำหนด ความยากเปลี่ยนตาม Shared State ไม่คงที่ทุกครั้ง
ไม่มี Target ที่สู้ต่อได้ ใช้ Default กลับจุดเกิดทันที + Invincible + Regen และ Idle จนเต็ม; รอ A / B ยังไม่เลือก ไม่ใช้รอ 1 นาทีหรือค้าง B เป็นกฎจริง
Echo ฟื้นตัว / ฮีลฉุกเฉินยังติด CD ไม่มีฮีลจาก Echo ระหว่างฟื้น; ช่วย Interact ตลอดตั้งแต่เริ่มใช้ 10 วินาทีแทน 40 วินาที; ฮีลฉุกเฉิน CD 10 นาทีไม่รีเซ็ตด้วยเรียกใหม่ Echo ไม่ใช่ประกันรอดหรือทรัพยากรรีเซ็ตฟรี
เต็มเป้าหมาย 48 คน / 6 ปาร์ตี้ อาจแยกกิจกรรมหรือรวมรอจุดเดียวกัน; ไม่ทราบจำนวนจุด / รอบเกิด / แรงจูงใจจริง Activities ไม่พิสูจน์ว่าแก้การกระจุกแล้ว
ห้องซ่อนถูกเปิดอยู่แล้ว คนมาทีหลังเข้าอ่านได้ แต่ไม่จำเป็นต้องแก้คำใบ้ซ้ำ Discovery ไม่เท่ากับ Puzzle ซ้ำได้ตลอด

นี่คือการเปรียบเทียบสถานการณ์บนกระดาษ ไม่ใช่ A/B Test กับผู้เล่น ไม่มีการแบ่งกลุ่ม วัดผล หรือเลือกผู้ชนะ

◇สิ่งที่ต้องสังเกตเมื่อมี Demo
  • เข้าใจหรือไม่ว่าต้อง ส่งครบชุด, กดศิลาเอง, เปิด Checkpoint และคุย NPC แยกกัน บันทึกจุดที่ต้องให้คนอื่นบอก ไม่ใช้ความจำของทีมแทนการอ่านหน้าจอจริง
  • อ่าน Frontal / Pool / การถอยได้ไหมเมื่อเล่นกับแพ้คจริง แยกการมองไม่เห็นสัญญาณออกจากการตัดสินใจรับความเสี่ยงเอง
  • เมื่อ B ว่าง / มี Adds / มีอีกปาร์ตี้ ผลการตัดสินใจต่างอย่างไร ไม่สรุปด้วยจำนวนมอนอย่างเดียว
  • วัดการรวมตัวที่ Main Route, ประตูบอส และ Activities เทียบสถานการณ์เดียวกันก่อนสรุปเรื่องการกระจายคน; ต้องกำหนดรอบเกิดและจุดกิจกรรมก่อน
  • ถามว่าผู้เล่นเข้าใจอะไรเกี่ยวกับสถานที่หลังจบ ไม่ถามนำว่ารู้สึก Cosmic Horror หรือไม่ และแยกผู้ที่อ่านกับไม่อ่าน Lore

◇อ่านส่วนนี้ก่อน

Rift of Catacomb เป็น Shared Dungeon ในแนวทาง Ragnarok ไม่ใช่ Instance Dungeon เป้าหมายประชากรชั้น 1 คือ 48 ผู้เล่นมนุษย์ = 6 ปาร์ตี้ ปาร์ตี้ละ 8 คน ไม่ได้หมายความว่าทุก Encounter ต้องใช้ 48 คน หรือว่าทุกห้องต้องรองรับทุกคนพร้อมกัน

ผู้เล่นเริ่มจาก Safe Zone สำรวจโซนฟ้า ทำเควสพื้นฐานและกลับส่งที่ทางเข้า จากนั้นอ้อมขึ้นฝั่งขวาไป Checkpoint รับช่วงเควสโซนแดง สำรวจสุสานชั้นใน ประกอบตราผนึก และปลดล็อกสิทธิ์เข้าห้องบอสรายคน การส่งเควสบอสที่ Checkpoint คือจุดจบ Quest Line ชั้น 1

แกนประสบการณ์ที่ออกแบบไว้:

  • โซนฟ้า: เรียนรู้การเลือกเป้าหมาย ต่อสู้ และสำรวจผ่านมอนพื้นฐาน
  • โซนแดง: อ่าน Frontal / LOS / Slow / พื้นอันตราย และรับมือ Elite กับกองมอนผสม
  • เปิดให้เตรียมพื้นที่ ใช้กำบัง / ต่างระดับ และเคลียร์กองสนับสนุนล่วงหน้าได้ ไม่บังคับวิธีเล่นเพียงแบบเดียว
  • มีกองยากเพื่อให้เกิดการเรียกคนมาช่วย จำนวนคนบนแผนที่เป็นคำแนะนำเบื้องต้น ไม่ใช่ Entry Requirement หรือผล Balance ที่พิสูจน์แล้ว
  • Optional Rite และ Lost Chamber เสนอเพิ่มทางเลือกนอก Main Route เพื่อลดเหตุผลที่ทุกปาร์ตี้ต้องไปรวมจุดเดียว แต่ยังไม่ยืนยันว่าจะแก้การกระจุกได้จริง

เรื่องสำคัญก่อนส่งต่อทำระบบ: ผู้เฝ้าสุสานห้องท้าย = Skeleton ใหญ่ 1F ยืนยันแล้ว; ยังต้อง Remap Content ลง Layout LD ใหม่, ตกลง Aggro Link, ป้าย 4 จุด, Personal Boss Access และ Spawn/Respawn. Core ใช้ WASD และแนวทาง 1+3/fake2 โดยเลี่ยง True Projectile; ไม่ได้ห้ามภาพการยิงทุกแบบ

ภาพนี้ใช้บอกประเภทพื้นที่ เนื้อหาคร่าว ๆ และกองมอน ไม่ใช่ตำแหน่ง Spawn หรือระยะ Collision ที่แม่นยำ สีโซนทับอยู่บนสี Indoor / Outdoor จึงไม่ควรนำสีทับไปตีความเป็น Geometry

บริเวณตามภาพ คำแนะนำในภาพ ข้อจำกัดการตีความ
ห้องด้านขวาบนโซนแดง 4–5 คน ยังไม่ใช่จำนวนที่เทสต์แล้ว
กองหน้าพื้นที่ขวาโซนแดง 6–8 คน วงแพ้คไม่ใช่รัศมี Aggro / Leash
แมงมุมและจุดตั้งรับฝั่งซ้าย 8 คนขึ้นไป จุด B มี Mage 1 + Melee 1 + Archer 1 ตามข้อสรุปก่อนหน้า
โถงหน้าประตูบอส 8 คนขึ้นไป อยู่บน Main Route ต้องยืนยันว่าหลีกเลี่ยงได้หรือเป็น Encounter บังคับ

ไม่เติมมอนหรือแก้ตำแหน่งในงานรวมเอกสารนี้ กองสนับสนุนแมงมุมเริ่มยืนรวมกันได้ตามทิศทางที่วางไว้ แต่ไม่อนุมานว่าทั้งกอง Aggro พร้อมกันอัตโนมัติหรือ Skill คลาสที่ยังไม่ CF จะ Cleave ได้ครบแน่นอน

Checkpoint อยู่ห่างประตูบอสค่อนข้างมากตามการตรวจพื้นที่ใน Unity ที่รายงานไว้ ไม่ใช้ระยะจากภาพนี้รับประกันว่ามอนจะไม่ตามถึง หรือย้ายจุดพักโดยพลการ

022. Player Flow และ Quest Line

ชื่อเควสชั่วคราว ยังไม่มี Quest ID / Item ID ในเอกสารนี้ ไม่กำหนดรางวัล

Flow หลัก: ทางเข้า → ชุด 1 ฝั่งซ้ายโซนฟ้า → กลับส่งทางเข้า → ชุด 2 อ้อมฝั่งขวาไป Checkpoint → ชุด 3 สำรวจโซนแดง → กลับส่ง Checkpoint → ชุด 4 เข้าบอส → กลับส่ง Checkpoint

Route เป็นคำแนะนำ ไม่บังคับลำดับเควสในชุด และไม่ใช่ภาพแสดง Placement ล่าสุดที่ตรงกันทุกไอคอน เส้นทางชุด 2 อ้อมฝั่งขวารอบพื้นแตกที่ Block ทาง ไม่ใช่ทางผ่านหรือจุดกระโดด

รับได้เมื่อยังไม่เคยส่งเควสนั้นสำเร็จ เลือกรับแยกหรือพร้อมกัน เริ่มนับหลังรับเควส

ชุด 4 — ผู้เฝ้าสุสาน

ผู้ให้ / ผู้รับส่ง: NPC ณ Checkpoint

รับได้หลังส่งชุด 3 ครบทั้งหมด และยังไม่เคยส่งเควสนี้สำเร็จ มีเควสเดียว Fall of the Gravewarden สองขั้นตอน:

  1. รับตราผนึกจาก NPC เมื่อรับเควส นำไป Interact จุดผนึกหน้าห้องบอส ใช้ 1 ชิ้นเพื่อเปิดสิทธิ์เข้าห้องเฉพาะตัวเอง สิทธิ์ไม่หายเมื่อตาย
  2. หลังใช้ตราสำเร็จ ได้เครดิตสังหารผู้เฝ้าสุสาน 1 ตัว แล้วกลับส่ง NPC Checkpoint เพื่อจบ Quest Line ชั้น 1

เครดิตใช้กติกาปาร์ตี้และข้ามปาร์ตี้ ไม่ตัดสิน Last Hit ต้องมีเควส ผ่านขั้นใช้ตรา และอยู่ในระยะเครดิต ตายค้างในพื้นที่ยังได้หากผ่านเงื่อนไข กลับเกิดนอกระยะแล้วไม่ได้

การรับเควสหรือใช้ตรา ไม่ทำให้บอสเกิดใหม่หรือรีเซ็ต บอส Spawn / Respawn เป็นอีกระบบหนึ่งที่ยังไม่กำหนดรายละเอียด

033. กติกา Quest กลาง

ส่วนนี้เป็นนิยามหลักร่วมกัน ไม่เพิ่มกฎใหม่ให้แต่ละ Quest Card

  1. รับ / ส่ง: เลือกรับทีละเควสหรือหลายเควสได้ แต่ต้องทำและส่งครบทุกเควสในชุดจึงเปิดชุดถัดไป รับ–ส่งและความคืบหน้าแยกรายคน โดยทั่วไปเริ่มนับหลังรับเควส ไม่จำเป็นต้องส่งพร้อมกัน
  2. สังหาร: สมาชิกปาร์ตี้ไม่ต้องตีเอง แต่ต้องมีเควสและอยู่ในระยะตอนมอนตาย ต่างปาร์ตี้ที่ร่วมสู้มีสิทธิ์เครดิต ไม่แย่ง Last Hit; นิยามร่วมสู้และรัศมีเครดิตต้องตกลงกับ Dev ระยะปรับหลังเทสต์
  3. ของดรอป: ผู้มีสิทธิ์เครดิตสังหารและมีเควสได้ดรอปส่วนตัว 100% ตัวละ 1 ชิ้น ต้องกดเก็บเอง ครบแล้วหยุดดรอป ส่งแล้วหักของออก จุดใดนับว่า “ครบ” เมื่อมีของตกแต่ยังไม่เก็บต้องระบุในระบบ Loot
  4. ป้ายบนพื้น: แต่ละคนเก็บเอง จุดละหนึ่งครั้งต่อเควส ต้องคนละจุดจนครบ ไม่หายจากคนอื่นเมื่อมีคนเก็บ ยังต้องตรวจ Anchor อย่างน้อย 4 จุดต่อพื้นที่เควส
  5. ศิลา: ผู้เล่นกดเองเฉพาะจุดที่กำหนด ไม่นับจุดเดิมซ้ำ คนอื่นจุดไฟแล้วไม่ปิดสิทธิ์ทำเควสของเรา
  6. Checkpoint / ตาย: เปิดรายคนเพื่อเปลี่ยนจุดเกิด คุย NPC ส่งเควสเป็นคนละขั้น ตายแล้วความคืบหน้าและของเควสไม่หาย
  7. บอส: สิทธิ์เข้าห้องรายคน ไม่เปิด / ปิดห้องทั้งเซิร์ฟเวอร์ เครดิตใช้หลักเดียวกับมอนตามเงื่อนไขชุด 4 ตายค้างในพื้นที่ยังอาจได้ แต่เกิดนอกระยะไม่ได้ ไม่มี Spawn / Reset ตามการรับเควส

แม้เครดิตและ Loot เป็นรายคน ศัตรูและโลกยังเป็น Shared World การมีสิทธิ์เครดิตไม่ได้หมายความว่าทุกปาร์ตี้มีมอนของตนเอง จึงยังต้องออกแบบการเกิดใหม่ให้สัมพันธ์กับจำนวนคน

4.1 Default Monster Reset — ใช้ร่วมทุกตัว

ข้อสรุปก่อนหน้ายังคงใช้ แม้ข้อความย่อในชุดล่าสุดจะเขียนเพียง “กลับจุดเกิด ฟื้น HP”:

  • ไม่มี Target ที่ต่อสู้ต่อได้ → เริ่มกลับจุดเกิด พร้อม Invincible + Regen ทันทีตั้งแต่เริ่มกลับ
  • ถึงจุดเกิดแล้ว Idle / ฟื้นต่อจนเต็ม จากนั้นจึงกลับพร้อมสู้ ฟื้นแบบค่อยเป็นค่อยไป ไม่เติมเต็มทันที
  • ไม่ไล่หรือโจมตีเข้า Safe Zone
  • Leash / การกลับกรณียังมี Target ต้องยืนยันนิยามกับ Core; ระยะและอัตรา Regen ยังไม่กำหนด
  • อาการ HP เต็มก่อนกลับถึงจุดเกิด และการตรวจ Target ถูกกำบัง / เข้าไม่ถึง ต้องตกลงก่อน Implement
  • การถอยแบบ Script ระหว่างยังสู้ เช่น Tarantula A → B ไม่ใช่ Reset จึงไม่ได้รับอมตะ / ฟื้น HP

4.2 Ghost — Basic Melee / Auto-Attack

เจตนา: ตัวพื้นฐานโซนแรก ใช้เรียนรู้เลือกเป้าหมายและโจมตี ไม่เปิดสู้ใส่ผู้เล่นที่เดินผ่าน

Ghost Slap: ลอยประชิด กระแทกเป้าหมายเดี่ยว ดาเมจเบา ใช้ Animation Attack ที่มี เตรียมกระแทกสั้น ๆ ไม่มีวงพื้น คิดดาเมจครั้งเดียว ไม่โดนรอบข้าง. ออกนอกระยะก่อนจังหวะโดนไม่สร้างดาเมจ แล้วเคลื่อนตาม; ไม่มี Frontal/AoE/CC/Debuff, ไม่มีการหลบกายภาพพิเศษ และไม่เรียกผีอื่นอัตโนมัติ

ถูกโจมตี → เข้าประชิด → Ghost Slap → พักตามรอบ → โจมตีซ้ำจนเป้าหมายตาย / หลุดระยะไล่ตาม หากไม่มี Target อื่นใช้ Default Reset ระยะไล่ตามต้องเทสต์ตามโซน

จังหวะตรวจ LOS/ระยะก่อนคิดผล, การยกเลิก และ Visual travel ยังรอยืนยัน. ไม่แทนด้วย Hit-scan/Instant guaranteed hit โดยอัตโนมัติ และไม่เพิ่มการบังกระสุนกลางทางแบบ True Projectile

066. Optional Activities — เพิ่มทำไม

6.1 Optional Rite — The Unquiet Vigil

ประเภท: Optional Combat Activity · ตำแหน่งร่าง: ห้องข้าง / Outdoor โซนแดง แยกเส้นถอยแมงมุมและทางเข้า Checkpoint ยังไม่ระบุ Anchor จริง

Lore ร่าง: พิธีเดิมส่งวิญญาณผู้ตายให้เดินทางต่อ แต่ผนึกชำรุดทำให้บางส่วนติดอยู่ในแท่น การเปิดพิธีดึงวิญญาณออกมา ผู้เล่นปราบและปิดผนึกเพื่อจบพิธี Vesper เกริ่นผ่านบทสนทนาได้โดยไม่ออกจากหน้าที่ และไม่ต้องมี Echo จึงเล่นได้

Loop: พบแท่น → ตรวจความเสี่ยง / เตรียมพื้นที่ / เรียกคน → กดเริ่ม → ต่อสู้และปิดผนึก → สำเร็จ

  • ไม่ต้องรับเควส ข้ามได้ มีสัญญาณก่อนเปิดว่าเกิด Combat และมีเตือนก่อนมอนปรากฏ
  • ใช้ Roster เดิมเป็นชุดจำกัด ไม่เสกไม่สิ้นสุด จำนวน / ชนิดยังไม่กำหนด
  • กดค้าง Interact ปิดผนึก เดิน / ยกเลิก / รับดาเมจขัดจังหวะและเริ่มร่ายจุดนั้นใหม่ จุดปิดแล้วเก็บ Progress ในรอบนั้น
  • สำเร็จเมื่อฆ่ามอนของพิธีครบและปิดผนึกครบ ฆ่าก่อนหรือแบ่งคนทำพร้อมกันได้ ไม่บังคับ Tactic
  • ต่างปาร์ตี้เข้าช่วยกลางทางได้ คนเปิดไม่ใช่เจ้าของแต่ผู้เดียว Activity credit โดยเฉพาะคนทำ Objective ยังรอกำหนด ไม่ใช้ Kill Credit แทนโดยอัตโนมัติ
  • แยกแท่น / State จากศิลาเควสส่วนตัว ไม่ทำให้คนอื่นทำ Quest ไม่ได้

ถอนตัว / ยกเลิก: คนเปิดออกแต่คนอื่นยังสู้ให้ทำต่อ หากมอนที่เหลือไม่มี Target ทั้งหมด ให้ยกเลิกรอบ ใช้ Default Reset กลับจุดเกิดพิธีพร้อม Invincible + Regen ข้อเสนอ Cleanup คือรอ HP เต็มแล้วนำมอนออกก่อนเปิดรอบใหม่ ไม่สร้างชุดซ้อน หากฆ่ามอนหมดแต่ผนึกไม่ครบ คนอื่นทำต่อได้ แต่เวลายกเลิกกรณีทิ้งไว้ยังไม่กำหนด

ยังต้องกำหนด: จำนวนผนึก / เวลากด / จำนวนคน / Roster / เวลาเกิดซ้ำ / ป้องกัน Trigger ซ้อน / ช่วงเตรียมตัวที่มอนยังไม่มี Target / เครดิต Objective

จุดตรวจดีไซน์: ฆ่ามอนก่อนอาจดีกว่าแบ่งหน้าที่เสมอ กติกานี้จึงเปิดโอกาสให้ร่วมมือ แต่ยังไม่พิสูจน์ว่าจะเกิด Cooperation จริง ไม่เพิ่ม Timer ลงโทษเพื่อบังคับแบ่งคนโดยไม่ได้ตกลง

6.2 Lost Chamber — The Forgotten Ledger

ประเภท: Optional Exploration Activity · ตำแหน่งร่าง: ห้องข้างโซนฟ้า ใกล้ Route เดิมแต่ไม่ทับป้าย / ศิลา ต้องให้ LD ตรวจ Geometry ไม่ขยายห้องโดยอัตโนมัติ

Lore ร่าง: ผู้ดูแลสุสานเคยเก็บรายชื่อผู้ตายในห้องเล็กเพื่อรักษาตัวตนของพวกเขา เมื่อสุสานไม่ปลอดภัยจึงซ่อนห้องและทิ้งสัญลักษณ์ไว้ บันทึกภายในชวนสงสัยว่าวิญญาณบางส่วนยังอยู่เพราะชื่อและเรื่องราวถูกลบเลือน เชื่อม Forgotten Names แต่ไม่เพิ่มของเก็บ / เงื่อนไข Main Quest และยังไม่ยืนยันว่าเป็นสาเหตุของวิญญาณทุกตัว

Loop: สังเกตร่องรอย → อ่านคำใบ้ → หาสัญลักษณ์ตรงกัน → เปิดทางลับ → สำรวจบันทึก

  • คำใบ้เช่นแสงจากรอยแยก / สัญลักษณ์บนผนัง เลือกแบบจริงกับ Art / LD จารึกใกล้ ๆ ชี้กลไก ไม่ต้องรู้ Lore นอกเกม
  • กดถูกเปิดทาง กดผิดให้ Feedback ไม่เสกมอนลงโทษหรือปิดสิทธิ์คนอื่น
  • ไม่ใช้ Skill คลาสหรือคนยืนสวิตช์พร้อมกัน ประตูเปิดร่วมกัน คนมาทีหลังเข้าได้ ไม่ต้องแก้ปริศนาซ้ำรายคน
  • บันทึกอ่านได้ทุกคน ไม่ถูกใช้หมดโดยคนแรก เป็นจุดจบเรื่องสั้น ไม่บังคับรับ / ส่งเควสหรือเก็บ Item
  • ดราฟแรกไม่จำเป็นต้องมีมอน เพื่อให้ต่างจาก Optional Rite
  • เปิดค้างเมื่อมีผู้เล่นในห้อง / ช่องประตู ไม่ปิดขัง เมื่อพื้นที่ว่างจึงคืนสถานะ เวลาและเงื่อนไข Reset ยังไม่กำหนด

ยังต้องกำหนด: ตำแหน่ง / คำใบ้ / ประตู / Exit / Occupancy detection / เวลา Reset และพฤติกรรม Interact พร้อมกัน

Catacomb 1F — Narrative ในเกม / Hub Connection

15 ตุลาคม 2026 · Authorized draft; บทพูดและการจัดวางใหม่ด้านล่างเป็นข้อเสนอ ไม่ใช่ Canon ที่ผ่านทีมแล้ว

011. แกนประสบการณ์

ผู้เล่นลงสุสานเพื่อรวบรวมสิ่งที่ยังตรวจสอบได้ แต่ยิ่งนำชื่อกลับมามาก บัญชีกลับยิ่งมีสิ่งที่อธิบายไม่ได้

Catacomb เป็นบทนำของ Rift of Death ไม่เฉลยผู้สร้าง Rift, สาเหตุหายนะ, ตัวตนหญิงนิรนาม หรือความรู้ทั้งหมดของ Vesper. ใช้โทน Cosmic Horror ผ่านความไม่ตรงกันของบันทึกและความไม่แน่ใจ ไม่เพิ่ม Sanity, ชื่อผู้เล่นถูกลบ, Time Loop หรือเหตุการณ์ระดับเซิร์ฟเวอร์

ชั้นข้อมูลมี 3 ระดับ:

  • จำเป็นต่อการเล่น: Objective/ตำแหน่ง/ผู้รับส่งใน Quest UI ใช้ภาษาตรง ไม่ซ่อนไว้ในคำเปรียบเปรย
  • เรื่องหลัก: บทพูดสั้นตอนรับ–ส่งเควส บอกว่ากำลังตรวจอะไรและพบอะไรเพิ่ม ข้ามได้
  • เรื่องเสริม: Inspect/ถามต่อ/Lost Chamber/Rite ทำให้โลกมีรายละเอียด แต่ไม่เก็บคำตอบที่จำเป็นต่อ Main Quest ไว้เฉพาะที่นี่
022. Hub → Catacomb — Connection proposal

Church → Threshold → ลานกลาง Hub → ทางลง Catacomb → ชานพักล่าง → Safe Room ทางเข้า 1F เดิม

ทางไป

  1. จากลานกลางมองเห็นป้าย Catacomb — ทางลงสุสาน และหัวบันไดได้ ไม่ใช้วง Portal เป็นภาพจำของสาขานี้
  2. ใช้หัวบันไดด้านตะวันตกเฉียงใต้ของ Hub ตาม Blockout ล่าสุดเป็น ตำแหน่งร่าง; ถ้าเดินชนเส้นทาง Registry ให้ปรับตัว Connector กับ LD ไม่ย้ายหน้าที่ Vesper
  3. บันไดลงสู่ชานพักที่เห็นแสง/สัญลักษณ์ของ Safe Room ข้างหน้า ผนังบังวิวชั้นในก่อนถึงประตูเพื่อให้การลงรู้สึกเป็น Threshold ไม่ใช่เห็นทั้งดันจากลาน Hub
  4. ปลาย Connector ต่อเข้าด้านนอก/ด้านหลังของ Safe Room ทางเข้าเดิม ไม่ต่อเข้าโซนล่ามอน, Checkpoint หรือหลังประตูบอส
  5. รับ Quest ชุด 1 จาก NPC ทางเข้าเดิม ไม่มี Quest ใหม่สำหรับปลดบันได และไม่บังคับรับ Echo หรือฟัง Vesper จบก่อนเข้า

ทางกลับ / กรณีผู้เล่นไม่พร้อมกัน

  • เสนอให้เส้นทางเดินย้อนขึ้นได้จาก Safe Room ทางเข้า ไม่ใช่ One-way drop. ถ้ามี Loading ให้ Landing สองฝั่งปลอดภัยและไม่ส่งคนลงกลางมอน; ยังไม่เลือก seamless/loading
  • ไม่เพิ่มปุ่มวาร์ปออก, ราคาเดินทาง, Checkpoint ใหม่ หรือกฎตายกลับ Hub. คนที่เปิด Checkpoint แล้วยังเกิดที่ Checkpoint ตามเดิม
  • สมาชิกปาร์ตี้เดินเข้าแยกกันได้; ไม่จำเป็นต้องดูบทพร้อมกัน ไม่มีระบบพากลุ่มวาร์ปอัตโนมัติที่ถือว่ามีแล้ว
  • การเดินเข้าดันไม่เท่ากับเปิด Checkpoint. จุดเกิดทางเข้าใช้กติกาเดิมของ Core; ร่างนี้ไม่เปลี่ยนจุดเกิดเพียงเพราะผ่านบันได
  • หลังจบ Quest ยังส่งที่ Checkpoint. จะกลับ Hub เพื่อทบทวนหรือไป Death ต่อเป็นทางเลือก ไม่ใช่เงื่อนไขจบชั้น 1F และไม่สร้าง prerequisite ใหม่ของ Death
  • Echo: ใช้ Lifecycle เดิมที่ทีมยืนยันภายหลัง ไม่ถือว่าข้าม Loading/Hub แล้ว CD ฮีลฉุกเฉินรีเซ็ต หรือได้ Echo ใหม่อัตโนมัติ

033. บทหลักพร้อมใช้ร่าง — ข้ามได้ ไม่เปลี่ยน Quest

ข้อความในเครื่องหมายคำพูดทั้งหมดเป็นบทที่ Codex เสนอใหม่. เลือกแสดงตามสถานะรายคน ไม่เล่นทับคนที่ Quest คืบหน้าต่างกัน

Beat 0 — Registry ก่อนลงสุสาน

Vesper: “ในสุสานมีป้ายชื่ออยู่มากกว่ารายชื่อในบัญชีนี้ จงเริ่มจากสิ่งที่เจ้ายังตรวจสอบได้ อย่าเพิ่งตั้งชื่อให้สิ่งที่เรายังไม่เข้าใจ”

ถ้าถามถึง Death: “สุสานเป็นเพียงส่วนหนึ่งของสิ่งที่รออยู่ ข้ามีรายงาน ไม่ใช่คำตอบทั้งหมด”

หน้าที่: ให้เป้าหมายและตั้งคำถามแรก ไม่แจก Quest เพิ่ม ไม่ต้องกลับมาส่งที่ Vesper

Beat 1 — NPC ทางเข้า / รับ Quest ชุด 1

NPC: “เริ่มจากสุสานฝั่งซ้าย นำป้ายชื่อที่ยังเหลือกลับมา จุดไฟศิลา และตรวจสิ่งที่หลงอยู่รอบหลุมศพ เราต้องรู้ว่าใครยังไม่ได้รับการจดจำ”

UI คง 4 เควส: ป้าย 4 จุด / ศิลาซ้าย 1 / Ghost 10 / ดรอป Ghost 5. เลือกรับแยกได้ ไม่บังคับทำศิลาก่อน

Beat 2 — ส่งชุด 1 / เปิดชุด 2

NPC: “ป้ายเหล่านี้ยังอ่านได้ แต่ช่องที่ควรมีชื่อในบัญชีกลับว่างอยู่ ข้าไม่รู้ว่าอะไรขาดหายไปก่อนกัน”

เมื่อรับชุด 2: “ตามแนวศิลาฝั่งขวาไป จุดไฟทั้งสองแห่ง ฝ่าแนวผู้เฝ้าทาง แล้วพบผู้ดูแลที่จุดพักด้านใน อย่าพยายามข้ามพื้นพังกลางทาง”

UI คงศิลาขวาล่างฟ้า+ขวาบนแดง / Skeleton แดงขวา 5 / เปิด Checkpoint. ทางอ้อมขวาเป็น Route เดิม ไม่เพิ่มการกระโดด

Beat 3 — ส่งชุด 2 ที่ Checkpoint / รับชุด 3

NPC Checkpoint: “แสงจากศิลายังมาถึงที่นี่ พักก่อน เจ้าคงเห็นแล้วว่าสุสานนี้ไม่ได้มีแต่ผู้ที่นอนสงบ”

เมื่อรับชุด 3: “สำรวจฝั่งซ้ายของชั้นใน นำชื่อกับเศษผนึกกลับมา และจุดศิลาที่ยังมืดอยู่ หากจะเปิดทางห้องท้าย เราต้องทำให้ตราสมบูรณ์เสียก่อน”

UI คงป้ายแดง 4 / ศิลาซ้ายบนแดง 1 / Skeleton แดง 10 / เศษผนึก 5. เปิด Checkpoint กับส่ง Quest เป็นคนละการกระทำ; บทพูดไม่ถือเป็นการเปิดจุดเกิดแทนผู้เล่น

Beat 4 — ส่งชุด 3 / รับชุด 4

NPC Checkpoint: “เศษผนึกประกอบกลับเป็นตราได้ แต่ชื่อที่เราพบยังไม่ทำให้บัญชีเล่มนี้สมบูรณ์ ผู้เฝ้าสุสานยังขวางห้องท้ายอยู่”

เมื่อรับ Fall of the Gravewarden และได้ตรา: “ใช้ตรานี้ที่ผนึกหน้าห้อง เข้าไปหยุดผู้เฝ้าสุสาน แล้วกลับมารายงานที่นี่ ทางเปิดได้ ไม่ได้หมายความว่าสิ่งที่อยู่ข้างในยอมให้ผ่าน”

ตราได้เมื่อรับ Quest ชุด 4 ตามเดิม ไม่แจกซ้ำตอนส่งชุด 3 และไม่เปิดห้องให้ทั้งเซิร์ฟเวอร์

Beat 5 — ใช้ตราที่หน้าห้องท้าย

ข้อความ Interact: “รอยต่อบนตราเข้ากับผนึกอย่างพอดี บานหินขยับ แต่จากอีกฟากหนึ่งไม่มีผู้ใดกล่าวต้อนรับ”

ข้อความสั้นหลังใช้ตราสำเร็จรายคน ไม่เพิ่ม Channel/Cutscene บังคับ ไม่หยุด Combat. HUD ยังบอกเป้าหมาย “สังหารผู้เฝ้าสุสาน 1 ตัว” ตรง ๆ

Beat 6 — ส่งชุด 4 / จบ Quest Line ที่ Checkpoint

NPC Checkpoint: “เจ้าผ่านผู้เฝ้าสุสานมาได้แล้ว เรามีชื่อกลับคืนมาหลายชื่อ แต่ยังไม่มีคำตอบว่าเหตุใดพวกเขาจึงติดค้าง อย่าให้การหยุดผู้เฝ้าทาง ทำให้เราคิดว่าสิ่งทั้งปวงจบลง”

ไม่กล่าวว่าบอสตายถาวรทั้งโลก ไม่บอกว่าปลดปล่อยทุกวิญญาณแล้ว ไม่เปิด Death โดยอัตโนมัติ และไม่บังคับกลับ Hub จึงนับว่าจบ

Beat 7 — ถ้าผู้เล่นเลือกกลับ Registry / Archive

Vesper: “ชื่อที่เจ้าพบทำให้ช่องว่างบางแห่งอ่านออก แต่บางแห่งกลับดูชัดขึ้นเมื่อมีชื่ออยู่รอบมัน เก็บสิ่งที่เห็นไว้ให้ดี ครั้งหน้าอย่าให้ความคุ้นเคยกลายเป็นคำตอบ”

Archive เสนอแสดงสรุปจาก Quest turn-in ที่มีแล้ว: สำรวจสุสานภายนอก / ไปถึงจุดพัก / รวบรวมผนึก / เผชิญผู้เฝ้าสุสาน. เป็นข้อมูล ไม่ใช่เก็บ Quest Item ที่ถูกหักคืนมา ไม่ใช้ข้อมูลการจบของคนอื่นมาเฉลยรายคน

044. Environmental snippets — ของเสริม ไม่บังคับอ่าน

ป้ายชื่อโซนฟ้า — ตัวอย่าง 4 ข้อความให้ Art/Quest ผูก Anchor

  1. “ชื่อหนึ่งยังชัดเจน ส่วนปีที่จารึกไว้ถูกสึกจนอ่านไม่ออก”
  2. “ใต้ชื่อมีคำสั้น ๆ ว่า ‘มีผู้รอรับ’ ไม่มีร่องรอยว่าผู้ใดเป็นคนเขียน”

  • บทสรุปของชุดใช้หลังส่งครบทั้งชุด; ส่งแค่บาง Quest ไม่กล่าวเหมือนรวบรวมครบแล้ว. หากไม่ดูตอนนั้น ให้เปิดย้อนหลังผ่านคุย NPC ได้
  • ป้าย/ศิลาที่คนอื่นใช้แล้วไม่กินสิทธิ์อ่านข้อความหรือทำ Objective ของเรา
  • ไม่บังคับอ่านข้อความครบ/ตอบคำถาม Lore เพื่อเปิด Quest ถัดไป; การอ่านไม่ใช่ prerequisite ใหม่
  • ไม่สมมติว่ามี personal Lore journal เพิ่มแล้ว. เวอร์ชันเล็กสุดใช้สถานะ Quest เดิมกับเมนูคุยย้อนหลัง; Archive แบบเต็มค่อยตรวจ Dev

ใช้ชื่อสื่อสารทีมว่า ผู้เฝ้าสุสาน 1F — Skeleton ใหญ่ / Tank Pressure. ใช้ Sword Strike, Crushing Strike, Growing Fury, Thunderous Roar และ Defensive Step ชุดเดิมเป็น combat draft ของ Encounter นี้ ไม่สร้างอีกตัวแยกระหว่าง Quest กับ Combat

  • เลิกใช้ “ยังไม่ใช่บอส” เป็นคำบรรยายปัจจุบันของตัวห้องท้ายนี้. เก็บที่มาความขัดกันในเอกสารเก่าเป็นประวัติ
  • Captain Ironrattle ยังเป็นชื่อใน Art Sheet ไม่ใช่ชื่อ Canon ที่ข้อสรุปล่าสุดยืนยันใหม่
  • ไม่มีหลักฐานให้สร้าง Large Skeleton อีกตัวนอกห้องท้ายโดยอัตโนมัติ
  • การเรียกมอนใกล้เคียง, ขอบ linked group, credit/access และ respawn ยังต้องคุยกับทีม ไม่ได้ถูกแก้เพียงเพราะยืนยันตัวตนแล้ว

R1 — Optional Rite / The Unquiet Vigil

พื้นที่เสนอ: มุมชานด้านเหนือของห้องในแดงขวาบน นอกวง P1; หมุดร่างประมาณ (407, 352)

เหตุผล: เป็นจุดเลือกแยกจากทางเข้า–Checkpoint และคนละฝั่งกับ Tarantula A→B; ผู้เล่นที่พร้อมสู้มีเหตุผลออกไปตรวจด้านข้าง โดยไม่ดึงพิธีมาอยู่ในคอ Main Route

  • หมุดคือจุดตรวจ/เปิดพิธี ไม่ใช่พื้นที่ Combat ที่ยืนยันว่าใส่ได้แล้ว. แถบเหนือห้องดูแคบใน Schematic จึงเป็น placement แบบมีเงื่อนไข ไม่ประกาศพร้อมใช้
  • ต้องวัด Net Walkable รอบแท่นและจุดผนึกให้มอน/ผู้เล่นเคลื่อนหลบได้ ไม่ใช้ Gross room ทั้งก้อนมาอ้างพื้นที่
  • มี Nameplate ทางเหนือและ Ghost ในบริเวณใกล้เคียง: ห้ามทับ Pickup anchors/ทางเข้าถึง; ไม่รวมมอนปกติเหล่านี้เป็น ritual-owned หรือย้ายมันออกเอง
  • ชุดมอนพิธีต้องมี Spawn anchors ใน Pocket ของตัวเอง; ห้าม Spawn ใส่ P1, ทางไปศิลาเควส, ทางผ่านโถง หรือหน้าผู้เล่นที่ไม่ได้กดเริ่ม
  • ถ้า Boundary ที่ LD ตรวจต้องล้ำทางศิลา/เส้นทางชุด 2 เพื่อให้เล่นได้ ให้ ไม่ใช้ R1 ในตำแหน่งนี้ แล้วทบทวน Pocket กับ LD; ไม่ขยายห้อง/แก้ Main Route โดยเงียบ ๆ
  • จำกัดให้มี 1 run ต่อแท่นตามดราฟ; จำนวนแท่นทั้งชั้น/จำนวนจุดพร้อมกันยังไม่ล็อก. ไม่สร้างสำเนาเพิ่มเพื่ออ้างว่ารองรับ 6 ปาร์ตี้แล้ว

การเล่นคงเดิม: ตรวจเตือน → เตรียม → เริ่มหนึ่งรอบ → มอนชุดจำกัด + ปิดผนึกด้วย Hold Interact → จบเมื่อทั้งสองอย่างครบ. ฆ่าก่อนค่อยปิดได้; คนอื่นช่วยได้; ไม่ถือว่าเกิด Cooperation แล้วจากการมีกติกาเพียงอย่างเดียว

L1 — Lost Chamber / The Forgotten Ledger

พื้นที่เสนอ: ช่วงผนังตะวันตกด้านบนของห้องย่อยล่างโซนฟ้าซ้าย; L1 หมุดร่างประมาณ (133, 661)

เหตุผล: อยู่แถวเส้นสำรวจชุด 1 แต่ไม่ใช่ศิลาซ้ายล่างหรือป้าย Quest; ให้ผู้สังเกตสิ่งแวดล้อมแยกจากการล่ามอนตามโถงกลาง โดยไม่ต้องพร้อมสู้เท่า Rite

  • เสนอห้องเก็บบันทึกตื้น ๆ หลังผนัง ขนาดและทางออกยังไม่ยืนยัน. ด้านนอกผนังนี้มีพื้นที่เดินเดิม จึงห้ามกินเส้นเดินไปศิลาหรือสร้างทางตันเพื่อใส่ห้องลับ. ต้องตรวจว่าฟิต/ปรับการแบ่งพื้นที่ได้หรือไม่; ถ้าไม่ได้ ให้ทบทวนกับ LD ก่อน ไม่ถือว่าอนุมัติห้องเพิ่มอัตโนมัติ
  • ทางเข้าห้องลับไม่เปิดทะลุข้ามพื้น Block, ผนัง Main Route หรือไปถึง Checkpoint/โซนแดง; เป็นปลายทางเสริมแล้วออกทางเดิม
  • คำใบ้ต้องมองเห็นจาก Walkable path ใกล้ ๆ ไม่ซ่อนหลังมอน/ของเก็บที่ถูกคนอื่นใช้แล้ว. ไม่ต้องฆ่า Ghost ในห้องย่อยเป็นเงื่อนไขเปิด
  • ไม่มีมอนใหม่ในห้องลับดราฟแรก. ภายในอ่านได้หลายคน ไม่ขัง/ปิดประตูขณะมีคนในห้องหรือช่องประตู
  • ถ้า Ghost เดิมเข้าถึงหน้าประตูได้ ไม่อ้างว่าพื้นที่นั้นปลอดภัย/เป็น Safe Zone; ผู้เล่นเลือกเคลียร์รอบ ๆ ได้

  5. Floor spawn / respawn และจำนวน Activity พร้อมกันจะใช้แนวทางใด เพื่อให้กลุ่มมาทีหลังยังมีทางเลือก?

คำถามเหล่านี้ยังไม่ถูกส่งให้ทีมโดยระบบนี้ รายการ Skill tuning / Tarantula A-B ที่พักไว้คงเป็น Deferred ไม่ใช้ขวางการส่ง Wrap-up วันนี้

055. ขอบเขตผลตรวจ

ตรวจความสอดคล้องของชื่อ บทบาทจำนวน Quest, Unlock vs Turn-in, Personal/Party/World State, หน่วยระยะ / เวลา / เปอร์เซ็นต์, Skill CD / Recovery / Reset, ภาพกับข้อความ, Asset identity และ Ownership จากข้อมูลที่ได้รับ

ตรวจไฟล์ภาพสำเนาครบ13และ Hash เทียบต้นฉบับ รวมถึง Link / Anchor ของเอกสารในเครื่อง ไม่ได้ทดสอบ Unity, AI, FPS / Network48คน, Combat balance หรือผลลดการกระจุก รายการความเสี่ยงในไฟล์นี้เป็นการวิเคราะห์เอกสาร ไม่ใช่ผล Playtest

ตรวจฉบับอ่าน Offline

ทำไฟล์ HTML เดียวที่ฝังภาพ13รูปและเอกสารประกอบ เปิดอ่านโดยไม่ต้องใช้ Internet ตรวจใน Headless Chrome ที่ Desktop1440pxและ Mobile390px: Link / Anchor ไม่มีจุดขาด, ไม่มี ID ซ้ำ, ภาพโหลดได้ครบ, ปุ่มเปิด–ย่อและการเลือกหัวข้อทำงาน, ไม่มี Page Error หรือหน้าล้นแนวนอนบนมือถือ ตรวจ Screenshot ภาพรวม Desktop / Mobile และส่วน Activity ด้วยสายตาประกอบ การตรวจนี้ยืนยันการแสดงเอกสารเท่านั้น ไม่ใช่การเทสต์เกม
